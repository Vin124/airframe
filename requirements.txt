opencv-python>=5,<6
mediapipe>=0.10,<0.11

windows-capture>=2,<3

# --- Optional: speech layer (Phase 12, run with --speech). The base pipeline
# runs without any of these installed (all imported lazily); they are heavy,
# so install them only when you want live transcription:
#   pip install sounddevice faster-whisper useful-moonshine-onnx
# sounddevice: PortAudio mic capture (16 kHz mono float32)
# faster-whisper: fallback ASR engine (CPU int8, base.en)
# useful-moonshine-onnx: preferred ASR engine (model 'moonshine/base') -- use
#   the PyPI wheel; the git-subdirectory install from the moonshine repo README
#   no longer builds since the repo was restructured.

# --- Optional: LLM parser (Phase 13, run with --speech --parse). No extra pip
# package is needed -- src/parser.py's OllamaClient speaks Ollama's HTTP API
# with the stdlib `urllib.request`. You do need the Ollama app itself running
# locally with a small model pulled:
#   1. install Ollama: https://ollama.com
#   2. ollama pull qwen2.5:1.5b   (or another small 1-3B instruction model)
#   3. `ollama serve` (or let the Ollama app run it) so localhost:11434 answers
# Without a reachable server the parser degrades to one stderr notice per
# phrase and the app keeps running with --speech's transcript-only output.

# --- Optional: retriever web-search fallback (Phase 14, run with --speech
# --parse). The DEFAULT Wikimedia Commons backend needs NO new dependency
# (src/retriever.py speaks the MediaWiki API + downloads images over the stdlib
# `urllib.request`). Only the web-search FALLBACK (used when Wikimedia returns
# nothing) needs `ddgs`; it's imported lazily, so its absence just disables that
# fallback and prints one notice:
#   pip install ddgs
# ddgs: keyless DuckDuckGo search (the maintained successor to duckduckgo_search).

# --- Optional: image generator (Phase 16, run with --speech --parse --generate).
# GPU-ONLY and opt-in: a parsed 'generate'-routed request runs a fast few-step
# diffusion model on the GPU and spawns the result like a retrieved image. The
# base pipeline and every other phase import/run WITHOUT any of these installed
# (torch/diffusers are imported lazily inside src/generator.py, only when
# --generate is passed). Needs an 8 GB+ CUDA GPU. Install the CUDA torch build
# from the official index, then the diffusers stack:
#   pip install torch --index-url https://download.pytorch.org/whl/cu124
#   pip install diffusers transformers accelerate safetensors
# torch: the CUDA build (match your CUDA runtime; cu124 shown for a modern NVIDIA).
# diffusers: the text-to-image pipeline (stabilityai/sdxl-turbo by default, fp16,
#   512 px, few-step; falls back to the lighter stabilityai/sd-turbo if OOM).
# transformers: the model's text encoder(s). accelerate: enables
#   enable_model_cpu_offload so the model fits 8 GB. safetensors: fast/safe
#   weight loading. The first generate is SLOW (model download + load); with no
#   CUDA GPU the generator prints one notice and generate requests are ignored.
